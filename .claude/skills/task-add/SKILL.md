# task-add

Vault のルートで作業する。ノートは `90_system/templates/task.md` に従い、`20_tasks/<タスク名>.md` に作る（1タスク1ノート、フラット）。

## 手順
1. **タスク名を決める**（日本語・簡潔。Windows で使えない文字 `\ / : * ? " < > |` は除く）。同名のノートが既にあれば、上書きせず、別名を提案する。
2. 次の項目を、ユーザーの発言から読み取る。足りないものだけ、まとめて聞く（聞き返しすぎない）。
   - `project`: `10_projects/` のプロジェクト名から該当を推奨として示す（`"[[プロジェクト名]]"` の形式）。属さなければ空。
   - `start` / `due`: `YYYY-MM-DD`。「明日」「来週金曜」などは日付に直して確認する。指定が無ければ、聞かずに当日にする（空にしない。当日開始の todo はデイリーの「遅れ」に出て、気づけるようにするため）。
   - `memo`: 任意。
3. `status` は `todo`（すでに着手中なら `doing`）。`completed` は空。`created` は今日。
4. ファイルを作り、結果を「作ったタスクと設定した値（当日を既定で入れた日付は、その旨）・次にやること（分解したいなら `task-split`）」で簡潔に報告する。

## 注意
- 完了済みとして作る場合は `status: done` と `completed` の両方を入れる。
- 既存のタスクは変更しない。
