# task

## 目的
アクションアイテムや口頭指示をタスクノートとして構造化する。

## 入力
議事録のアクションアイテム、またはCLI入力。

## 出力
`Task_Template.md` ベースのノート
（`10_Projects/<Name>/Tasks/`、プロジェクト不明なら要確認）。

## 処理ステップ概要
1. 入力からタスク内容を抽出
2. 紐づくプロジェクトを特定（不明なら確認を求める）
3. `Task_Template.md` からノート作成し `status: 1_todo` をデフォルト
   セット
