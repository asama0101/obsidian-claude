# close

## 目的
1日の作業内容を確定し、mainブランチへ統合する。

## 入力
なし（現在のブランチ＝当日ブランチを対象とする）。

## 出力
- 当日デイリーノートの「🔗 本日作成・更新したノート」セクションへの
  リンク追記
- 当日ブランチのコミット
- `main` へのマージ
- （`origin` が設定されていれば）マージ後 `main` の push

## 処理ステップ概要
1. `git merge-base main HEAD` で当日ブランチの分岐点を求め、
   `git diff --name-only <分岐点> HEAD` で当日作成・更新された
   `.md` ファイル一覧を取得する（当日デイリーノート自身・
   `70_Templates/`配下・`.claude/`配下は除外する）
2. 対象ファイルへの `[[wikilink]]` を、当日デイリーノートの
   `<!-- UPDATED_NOTES_START -->`〜`<!-- UPDATED_NOTES_END -->` 内に
   一覧として書き込む（プレースホルダ文言は上書きする）
3. 現在のブランチ（当日ブランチ）の変更をコミット
4. `main` にマージ
5. `git remote` に `origin` が設定されていればマージ後の `main` を push
6. 当日ブランチ自体は削除せず残す
