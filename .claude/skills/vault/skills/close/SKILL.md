# close

## 目的
1日の作業内容を確定し、mainブランチへ統合する。

## 入力
なし（現在のブランチ＝当日ブランチを対象とする）。

## 出力
- 当日ブランチのコミット
- `main` へのマージ
- （`origin` が設定されていれば）マージ後 `main` の push

## 処理ステップ概要
1. 現在のブランチ（当日ブランチ）の変更をコミット
2. `main` にマージ
3. `git remote` に `origin` が設定されていればマージ後の `main` を push
4. 当日ブランチ自体は削除せず残す
