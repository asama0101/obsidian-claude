# プロジェクト自動紐付けルール（meeting / clip 共通）

`vault_lib.fuzzy_project_match(text, projects_dir)`が担う。

1. `10_Projects/`直下のディレクトリ名一覧を取得する。
2. 対象テキスト（meetingならイベントの`summary`+`description`、clipなら
   ページタイトル+要約）に対し、各プロジェクト名（3文字以上の
   トークン）が部分一致するか確認する。
3. 一致したプロジェクトが**ちょうど1件**の場合のみ`project`へ
   `"[[プロジェクト名]]"`形式で自動設定する。
4. 0件または2件以上一致した場合は`project`を空欄のまま作成する
   （曖昧な自動割当はしない）。

taskスキルはこのルールを使わない。不明なら必ずユーザーに確認する
（meeting/clipは同期件数が多くなりうるため都度確認しない方針だが、
taskは1件ずつの明示的な作成なので確認コストが低く、誤った自動割当を
避けることを優先する）。
