# プロジェクト自動紐付けルール（meeting専用）

`vault_lib.fuzzy_project_match(text, projects_dir)`が担う。

1. `10_Projects/`直下のディレクトリ名一覧を取得する
   （`vault_lib.list_project_names`）。
2. 対象テキスト（イベントの`summary`+`description`）に対し、
   各プロジェクト名（3文字以上のトークン）が部分一致するか確認する。
3. 一致したプロジェクトが**ちょうど1件**の場合のみ`project`へ
   `"[[プロジェクト名]]"`形式で自動設定する。
4. 0件または2件以上一致した場合は`project`を空欄のまま作成する
   （曖昧な自動割当はしない）。0件だった予定は`no_project`として
   まとめてユーザーに確認する。

task・clipスキルはこのルールを使わない。taskは1件ずつの明示的な作成
なので確認コストが低く、誤った自動割当を避けることを優先して必ず
ユーザーに確認する。clipはWebクリップに対するproject自動紐付け機能
自体を持たない。
