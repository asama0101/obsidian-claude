# デイリーノート・ダッシュボード・ガント

## デイリーノート
- 作成は `daily-start`、ガントだけの更新は `gantt-update`、締めは `daily-end`。
- セクションはテンプレート `90_system/templates/daily.md` の順。「今日の予定」「今日の実績」は置かない。「振り返り」は `daily-end` が書く。
- `<!-- gantt:start -->` 〜 `<!-- gantt:end -->` の間は `daily_start.py` が再生成する。マーカーは消さず、間を手で書かない。
- 「今日のメモ」の行は、締めの棚卸しで振り分け、行末に ` → [[ノート名]]` の印を付ける。印のある行と、過去のデイリーのメモは対象にしない。

## 「遅れ」の定義
- `todo` で `start` が基準日以前、または `in_progress` / `waiting` / `requested` で `due` が基準日より前。
- IMPORTANT: 定義を変えるときは、`90_system/bases/daily-tasks.base` の式と `daily_start.py` の `is_late` の両方を直す。

## ダッシュボード（Bases）
- 対象は `20_tasks/` と `00_inbox/` の直下のタスク。
- タスクの表は区分でグルーピングする: 1 遅れ → 2 今日が期限 → 3 作業中 → 4 依頼中 → 5 保留 → 6 今日完了。1つのタスクは最初に該当した区分にだけ出る。
- `idea` は「アイデア・インボックス」にだけ出る。`shelved` / `cancelled` はどの一覧にもガントにも出さない。
- 基準日は、ノートのファイル名の日付（なければ今日）。

## ガント
- 表示期間は、ノートの日付〜90日後（`PAST_DAYS` / `FUTURE_DAYS`）。はみ出す分は端で切り、`←` `→` を付ける。
- 遅れは赤、`in_progress` は強調、`waiting` は名前の先頭に `⏸`、`requested` は `✉`。
- 「遅れ」に当たるタスク（未完了で `due` が基準日より前、`start` が基準日より前の `todo`）は、ガントに出さない（ダッシュボードの「遅れ」で見る）。完了済みは、その日に完了したものだけ出す。
- チェックリストの項目は、ガントのマーカーの間にあるものだけを、マイルストーン（◇）としてタスクの表示開始日の位置に出す。期限が基準日より前の未完了は赤、完了はグレー。期限は名前の後ろに付くだけで、位置は変わらない。
- 過去のデイリーノートのガントは、その日のスナップショットとして固定される（Bases の表示は今の状態になる）。
