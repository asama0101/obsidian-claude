# 議事録

- ファイル名は `YYYY-MM-DD_会議名.md`。作成とタスク化は `meeting-import`。
- プロパティ: `date`（開催日）・`project`・`location`（会議室名・Teams など自由記入）・`source`（取り込み元。会議の URL・ID や元のファイル名）。
- 参加者はプロパティにせず、本文の `## 参加者` に1人1行（`- 名前（所属・役割は任意）`）で書く。
- アクションアイテムは `- [ ] 内容 期限:YYYY-MM-DD`（期限は省略可）。担当は書かない。他の人に頼んだものは、タスクの `status: requested` で表す。
- タスクにしたアクションアイテムの行末には ` → [[タスク名]]` が付く。印のある行は処理済みなので、二重にタスクにしない。
